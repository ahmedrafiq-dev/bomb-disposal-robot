# Bomb Disposal and Detection Robot

## 🚀 Overview
A remotely operated robotic system designed for safe bomb detection and disposal in hazardous environments.

## ⚙️ Features
- 5-DOF robotic arm for object handling  
- Wireless control using ESP32 / Raspberry Pi  
- Real-time video streaming for surveillance  
- Remote navigation with ~30–50m range  
- Mechanical gripper and disruptor system  

## 🧠 Technologies Used
- ESP32 / Raspberry Pi  
- Embedded C / Python  
- PWM motor control  
- Camera module (live streaming)  

## 🎯 Objective
To design a low-cost, scalable robotic system for safety-critical applications such as bomb disposal.
